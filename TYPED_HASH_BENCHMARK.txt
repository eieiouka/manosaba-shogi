What changed:
- Removed Map<string,nodeId> from the graph builder.
- Removed one 49-character JS string object per position.
- Canonical positions are stored as exact 49-byte records in one Uint8Array.
- Deduplication uses an open-addressed typed-array hash table.
- Two 32-bit hashes are only filters; every candidate match is byte-compared,
  so hash collisions cannot merge distinct game positions.
- CSR edge storage from v7 is retained.

This is an exactness-preserving optimization.
No opening move is declared best from these capped graph benchmarks.
